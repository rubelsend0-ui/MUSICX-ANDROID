# MUSICX - Native Android Music Player for Self-Hosted Audio API

Production-grade, modern Jetpack Compose audio player engineered specifically for your self-hosted Termux / Cloudflare audio streaming backend.

## Tech Stack
- Kotlin & Jetpack Compose (Material 3 Dark Glassmorphism)
- AndroidX Media3 ExoPlayer & MediaSessionService
- Retrofit & OkHttp with Dynamic Token Interceptor
- Android Keystore-backed AES-256 Encrypted SharedPreferences
- GitHub Actions automated debug APK workflow
